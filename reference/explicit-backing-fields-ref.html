Explicit Backing Fields — Quick Reference

Stable · Kotlin 2.4 ← Lesson 2

Syntax

val propertyName: PublicType
field = concreteSubtypeValue()          // type inferred

val propertyName: PublicType
field: ConcreteSubtype = concreteSubtypeValue()  // explicit

The subtype rule

// ✓
val items: List<String>
field = mutableListOf<String>()          // MutableList ⊆ List

// ✓
val count: StateFlow<Int>
field = MutableStateFlow(0)              // MutableStateFlow ⊆ StateFlow

Eligibility — property must be

  • ✓ val
  • ✓ No custom getter
  • ✓ Not open
  • ✓ Not delegated (by …)
  • ✓ Not const

Canonical real-world use

// Before 2.4
private val _count = MutableStateFlow(0)
val count: StateFlow<Int> = _count.asStateFlow()

// Kotlin 2.4
val count: StateFlow<Int>
field = MutableStateFlow(0)

Inside vs. outside the class

Location Visible type
Inside the class Concrete backing field type (e.g. MutableList)
Outside the class Declared property type (e.g. List)
