@IntroducedAt — Quick Reference

Experimental · Kotlin 2.4 ← Lesson 6

Opt-in

@OptIn(ExperimentalVersionOverloading::class)

Syntax

@OptIn(ExperimentalVersionOverloading::class)
fun MyFun(
    existing: Type = default,
    @IntroducedAt("1.1") newParam: Type = default,
    @IntroducedAt("1.2") anotherParam: Type = default,
) { }

What the compiler generates

Callers compiled against Hidden overload kept
Before v1.1 MyFun(existing)
v1.1 MyFun(existing, newParam)
v1.2+ (current) The real function — no hidden overload

vs @JvmOverloads

@JvmOverloads @IntroducedAt
Overloads All trailing-default combos One per version boundary
Visible to source? Yes (public) No (bytecode only)
Primary goal Java interop Binary compatibility

Use when

  • You publish a compiled library artifact
  • You're adding optional parameters to an existing public API
  • You need pre-compiled callers to keep working without recompiling
