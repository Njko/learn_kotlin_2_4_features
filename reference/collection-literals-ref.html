Collection Literals — Quick Reference

Experimental · Kotlin 2.4 ← Lesson 3

Enable

// build.gradle.kts
freeCompilerArgs.add("-Xcollection-literals")

Type inference table

Expected type Desugars to
List<T> / no annotation listOf(…)
MutableList<T> mutableListOf(…)
Set<T> setOf(…)
MutableSet<T> mutableSetOf(…)
Custom with operator fun of CustomType.of(…)

Custom type hook

class MyCollection(...) {
    companion object {
        operator fun of(vararg items: T) = MyCollection(...)
    }
}
val x: MyCollection = [item1, item2]  // → MyCollection.of(item1, item2)

Limits

  • No map literals — use mapOf("k" to v)
  • Cannot construct Java collection types
  • Experimental — syntax may change
