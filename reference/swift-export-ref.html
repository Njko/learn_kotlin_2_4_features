Swift Export — Quick Reference

Alpha · Kotlin 2.4 ← Lesson 5

Kotlin → Swift type map

Kotlin Swift
suspend fun async func
Suspend lambda async closure
Flow<T> AsyncSequence via .asAsyncSequence()
Kotlin exception Swift Error (try)
Coroutine cancellation Swift Task cancellation

Calling suspend from Swift

// Kotlin
suspend fun fetchUser(id: String): User

// Swift
let user = try await fetchUser(id: "u1")

Consuming a Flow in Swift

// Kotlin
fun prices(): Flow<Double>

// Swift
for try await price in prices().asAsyncSequence() { }

Swift Package dependency in Gradle

kotlin {
    swiftPMDependencies {
        swiftPackage(
            url = url("https://github.com/…"),
            version = from("1.0.0"),
            products = listOf(product("ProductName"))
        )
    }
}
