# User knows Kotlin and wants to stay current with 2.4

User is an existing Kotlin practitioner. Goal is not to learn Kotlin basics but to understand the new concepts in 2.4 well enough to recognise when and how to use them. Lessons should skip fundamentals and go straight to the new feature, the problem it solves, and when to reach for it.

**Implications:** Skip syntax basics, class declarations, lambdas, etc. Assume familiarity with coroutines, extension functions, and idiomatic Kotlin patterns. The right level is "senior engineer reading a well-motivated RFC."
