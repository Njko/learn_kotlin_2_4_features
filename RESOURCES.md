# Kotlin 2.4 Resources

## Knowledge

- [What's new in Kotlin 2.4.0 — kotlinlang.org](https://kotlinlang.org/docs/whatsnew24.html)
  Primary source. Comprehensive feature list with code examples. Use for: any Kotlin 2.4 feature detail, official syntax, stability status.

- [Kotlin 2.4.0 Released — JetBrains Blog](https://blog.jetbrains.com/kotlin/2026/06/kotlin-2-4-0-released/)
  Editorial overview of the release. Use for: motivation behind features, the big-picture story of the release.

- [Context Parameters design doc — KEEP-367](https://github.com/Kotlin/KEEP/blob/master/proposals/context-parameters.md)
  The KEEP proposal for Context Parameters. Use for: the full rationale, edge cases, comparison with Scala givens and Haskell typeclasses.

- [Kotlin releases page](https://kotlinlang.org/docs/releases.html)
  Tracks all stable, RC, and EAP releases. Use for: version history, release cadence.

## Wisdom (Communities)

- [Kotlin Slack — #language-evolution channel](https://kotlinlang.slack.com)
  Where JetBrains engineers and contributors discuss language proposals. High signal. Use for: real practitioner reactions to new features.

- [r/Kotlin](https://reddit.com/r/kotlin)
  General Kotlin community. Use for: real-world adoption questions, how teams are actually using new features.

- [Kotlin Discussions — discuss.kotlinlang.org](https://discuss.kotlinlang.org)
  Official forum. Use for: asking nuanced questions about language semantics, getting answers from core team members.
