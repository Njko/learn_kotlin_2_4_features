# Mission: Kotlin 2.4 Concepts

## Why
You keep up with Kotlin as it evolves and want fluent, confident understanding of the new concepts in 2.4 — not just awareness that they exist, but the ability to recognise when and why to use them in real code.

## Success looks like
- Can explain and use Context Parameters (now Stable) without looking up syntax
- Understand Explicit Backing Fields and when they replace a companion-object pattern
- Know which 2.4 features are Stable vs Experimental, and what that means for production use
- Can identify opportunities in existing code where 2.4 features would simplify things
- Understand the impact on Kotlin Multiplatform (Swift Export Alpha, Swift Package imports)

## Constraints
- Already knows Kotlin — lessons should not re-teach basics
- Goal is depth + retention, not a changelog read-through

## Out of scope
- Build tooling (Gradle/Maven changes) unless directly relevant to using language features
- Compose compiler internals
- Kotlin/Wasm deep-dives (unless requested)
